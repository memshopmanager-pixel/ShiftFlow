# ShiftFlow
**Планируй смены. Контролируй время. Работай проще.**

Современное приложение для управления сменами в стиле Liquid Glass iPhone.

## Что в проекте
- Календарь с выбором месяца и выделением текущего дня
- Добавление смены прямо из календаря
- Отчёты по месяцам и годам
- Статистика по рублям, часам и сменам
- Выбор языка: Россия / Америка
- Тёмная и светлая тема
- Пользовательское соглашение

## Как открыть
Откройте файл `index.html` в браузере.

## Структура
- `index.html` — основной интерфейс
- `style.css` — оформление в стиле Liquid Glass
- `script.js` — логика переключения вкладок и добавления смен
